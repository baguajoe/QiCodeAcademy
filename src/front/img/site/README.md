# Site photos

Drop real photos here using the exact file names listed in `/IMAGE_GUIDE.md`
(for example `hero-home.jpg`, `founder-portrait.jpg`). The next build picks them up
automatically and replaces the placeholder — no code changes needed.

- Accepted formats: `.jpg`, `.png`, `.webp`
- A photo uploaded in the admin panel (Site images) always takes priority over a file here.
- Only use photos of people who have given photo/video consent.
